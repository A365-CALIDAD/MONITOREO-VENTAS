# Monitoreo de Calidad de Ventas

Dashboard estático para las validaciones de ventas de Claro Ecuador.

## Fuente de datos

La página consume la hoja pública de Google Sheets definida en las constantes `SHEET_ID` y `GID` de `index.html`. Para cambiar la fuente, reemplace ambos valores y confirme que la hoja permita exportación CSV.

## Publicación

GitHub Pages puede publicar este repositorio desde la rama `main` y la carpeta raíz. No se requieren credenciales ni backend para visualizar el tablero.

Los teléfonos se usan solo para identificar duplicados y no se muestran en el dashboard.
